How to open links in a specific Chrome profile on Mac

You click a link in Slack, and it opens in your personal Chrome. Again. Here’s why that happens, the three ways around it that Chrome already gives you, and the one-click fix.

Why Chrome picks the wrong profile

When you click a link in another app (Slack, Mail, Notion, Calendar), macOS hands it to your default browser. It hands it to the browser, not to a profile. Chrome then opens the link in whichever profile window you used last.

So if you were just reading something in your personal profile, the work link from Slack lands there too: logged into the wrong Google account, “You need access”, the wrong Jira, the wrong everything. Chrome on Mac has no setting to say “links from Slack go to Work” or “docs.google.com always opens in Work”.

Way 1: “Open link as” (built into Chrome)

If the link is already inside Chrome, right-click it. When you have more than one profile, the menu has Open link as, with a list of your profiles. Pick one and the link opens in that profile’s window.

It works, but only for links that are already in Chrome. A link from Slack has already opened in the wrong profile by the time you can right-click anything. Most people end up copying the address, switching profiles, opening a new tab and pasting. Every single time.

Way 2: open the right window first

Chrome uses the profile you used last. So before you click the link in Slack, click on a window of the profile you want, then go back to Slack and click. The link follows that window.

This is free and needs nothing installed, but you have to remember it before every click, and it breaks the moment you touch the other profile.

Way 3: Terminal, for one-off links

Chrome can be told which profile to use from the command line. First find the profile’s folder name: in that profile, open chrome://version and look at Profile Path. The last part is the folder, usually Default for the first profile and Profile 1, Profile 2 and so on after that. Then:

open -na "Google Chrome" --args --profile-directory="Profile 1" "https://example.com"

Good for scripts and shortcuts. Useless for links you click in other apps, because macOS doesn’t run this when you click.

Other browsers

Microsoft Edge has a setting for one default profile for links from other apps. That fixes it if you only ever want one profile for outside links, but not when work links should go to Work and personal ones to Personal. Brave and Vivaldi behave like Chrome.

The fix: pick a profile per site, once

What you actually want is a rule per site: “docs.google.com opens in Work, youtube.com opens in Personal”. macOS can’t do that on its own, because it only knows browsers. The way to get it is a small app that sits in place of your default browser, looks at each link, and passes it to the right browser profile.

That’s what Profiley does. It’s free and open source, for Mac:

  1. Install it. It finds the browser you use and its profiles, pictures and all. Your Mac asks to make Profiley the default browser: say yes. That’s how links reach it.
  2. Click any link. The first time you open a site, a small window asks which profile. Click one, or press 1, 2 or 3.
  3. Tick to remember. Next time that site opens straight in the right profile, with no asking.

Hold Shift while clicking a link to get the question back for a site you saved. Open Profiley from Spotlight to see, edit or remove every saved site. It works with Chrome, Comet, Brave, Edge and Vivaldi on macOS 12 or later. There’s no extension and no account, and your saved sites live in one file on your Mac.

One honest catch: Profiley isn’t signed by Apple yet, so the first time you open it your Mac asks you to confirm once. The install steps show exactly where to click.

Other apps that do this

Profiley isn’t the only one. Choosy (paid) and Velja pick a browser for each link too, and Finicky does it if you write your rules in a JavaScript config file. Profiley’s difference is that it’s built around profiles first: it asks the first time and learns, so there’s nothing to configure up front.
