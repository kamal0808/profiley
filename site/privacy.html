Privacy

Last updated 20 October 2026

The short version

The Profiley app sends one thing: an anonymous count, so we know how many people installed it and use it each day. No account, no names, no links, no sites, no profiles. Everything else stays on your Mac, and you can turn the count off.

What the app reads

To show your profiles, Profiley reads your browser's Local State file (for example ~/Library/Application Support/Google/Chrome/Local State) for each profile's name, colour and picture. It doesn't read your history, cookies, passwords or anything else in your browser.

When you click a link, Profiley sees that link so it can open it in the profile you pick. It passes the link to your browser and keeps nothing, except the line macOS writes to your Mac's own system log saying which link opened in which profile.

If you used an older Finicky-based setup, on first launch Profiley reads ~/.finicky.js once to bring over the sites you had saved.

What the app saves

When you tick “Always open … this way”, Profiley saves the site's domain and the profile's name in ~/Library/Application Support/Profiley/sites.json. It also keeps, in its macOS settings, which browser you use and the random ID and last date for the usage count. Both stay on your Mac. Delete that folder, or remove sites in Profiley, and they're gone.

The usage count

From version 1.6, the first time you use Profiley and then at most once a day while you use it, it sends one short message to PostHog, an analytics service. The message holds a random ID made on your Mac (so one person counts once), whether it's a new install or a daily use, and the Profiley version. That's all. PostHog makes no profile of you from it, and it sees the IP address the message came from, as any web request does.

To turn it off, run this in Terminal: defaults write com.kamalkhatwani.profiley analytics -bool false

This website

The site is hosted on Netlify, which keeps standard server logs (like IP addresses) to run it. Fonts load from Google Fonts. The download comes from GitHub. Each of these has its own privacy policy. The site itself uses no cookies and no analytics.

If you send feedback, your answers, and your email if you leave one, are stored with Netlify Forms, which also records the IP address and browser the form came from. We use them only to read your feedback and reply. We never sell or share them. Ask through the feedback form and we'll delete yours.

Changes and questions

If this changes, this page changes, with a new date at the top. Profiley is open source, so you can check all of this in the code. Questions go through the feedback form or GitHub issues.
